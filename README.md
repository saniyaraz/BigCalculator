# 🧮 Advanced Calculator

A **numerical calculator** written in C++  that supports **large numbers and decimal operations**.  
Perfect for performing addition, subtraction, multiplication, and division with long decimal numbers.

---

## ⚙️ Features

- Addition, subtraction, multiplication, and division of large numbers  
- Supports long decimal numbers  
- User input validation  
- Properly formatted output  
- Simple terminal-based interface  

---

## 🧰 Languages & Tools

- **C++** for core calculation logic  
- **Python** (optional for extended version)  
- Terminal / CLI interface
